# Plantilla de contexto

Un solo archivo de texto para que ChatGPT, Claude o cualquier otra herramienta de IA trabaje con ustedes sin tener que explicarle todo de nuevo cada vez.

- **[contexto.md](contexto.md)**: la plantilla. [Versión en texto plano](https://raw.githubusercontent.com/SrRubencho/plantilla-contexto/main/contexto.md) para copiarla directo.
- Por qué existe y cómo la uso: [El modelo cambia, el contexto es mío](https://rubendurango.com/notas/el-contexto-es-mio).

## Uso rápido

1. Copiar `contexto.md` y llenarlo.
2. Subirlo como archivo a un Proyecto de ChatGPT o de Claude.
3. Guardar el original fuera de la app; esa es la fuente de verdad.
4. Al cerrar una conversación con avances, pedir que proponga cambios, decidir qué entra y actualizar el original.
